# 08 刘冰团队定向：多模态、脑动力学与跨尺度解释

> 目标：说清楚为什么整合模态、每种模态贡献什么、如何验证增量价值，以及跨尺度关联不能推出什么。论文编号和 DOI 见 [references_papers.md](references_papers.md)，通用模态解释见 [06_cognitive_neuroscience_bridge.md](06_cognitive_neuroscience_bridge.md)。

## 1. 研究主线与回答骨架

团队工作可概括为：用结构/功能影像刻画个体与疾病相关脑组织，以动态模型描述时间变化，再借助遗传、转录组或其他分子图谱寻找跨尺度对应，并在发育或临床数据中检验泛化。

“为什么多模态”的合格回答有四句：MRI 提供空间结构和慢时间尺度组织，EEG/电生理提供毫秒动力学，遗传/转录组提供可能的分子背景；融合用于检验互补信息；必须与单模态基线比较增量效度；模态间空间相关不自动构成分子机制或因果链。

## 2. 十篇代表作速读卡

### L01 Spontaneous brain regional dynamics contribute to generalizable brain-behaviour associations（2025）

- **研究问题**：题名表明关注自发局部脑动力学是否促进可泛化的脑—行为关联。
- **数据/对象/方法边界**：当前只核验正式元数据，未获得可核验摘要；不补写队列、样本量、具体动力学指标或效应。
- **为什么多模态/价值**：此工作首先是“动态影像—行为”问题；只有原文使用额外模态时才能称多模态。
- **局限与精读任务**：核查 discovery/validation 划分、行为构念、区域动力学定义、头动与扫描时长控制、跨数据集泛化及相对静态特征的增量。
- **未来/可能追问**：动态特征为什么可能比静态均值更有信息？答时间组织可能承载行为差异，但必须证明可靠性和样本外增量。

### L02 Genetic and striatal structural connection linking BIS/BAS to adolescent anxiety and depression（2025）

- **研究问题/对象**：BIS/BAS 多基因风险如何关联纹状体结构连接梯度和青少年情绪易感性；ABCD 数据 1,929 人，平均年龄 9.95 岁，女性 50.39%。
- **数据/方法**：GWAS 派生 polygenic risk score（PRS）、扩散 MRI 概率纤维追踪、纹状体 connectopic mapping/结构梯度及基因—脑—行为多变量/中介模型。
- **主要发现**：BIS 与 BAS 遗传风险对纹状体结构梯度呈可区分关系；较高 BIS 风险关联焦虑，BAS 风险更关联抑郁和退缩特征。
- **为什么多模态**：遗传给易感背景，dMRI 给结构通路，量表给心理表型；三者对应比任一模态单独更接近跨尺度问题。
- **局限/未来**：PRS 依赖祖源与 GWAS 质量；观察性中介不证明发育机制。需纵向、跨祖源复现和时间顺序检验。

### L03 Predicting antipsychotic efficacy from resting-state connectome（2025）

- **研究问题/对象**：基线静息态连接能否预测精神分裂症患者 8 周抗精神病药疗效；发现队列 105 人，独立验证 52 人。
- **数据/方法**：基线/治疗后 PANSS，基线 rs-fMRI 连接矩阵和 connectome-based predictive model；发现集留一法，外部队列验证。
- **主要发现**：预测 PANSS 总分减分率，发现集 r=.59、MSE=.021，验证集 r=.41、MSE=.036；正/负预测连接涉及顶叶、额顶控制网络及小脑—丘脑—皮层连接。
- **为什么多模态**：这里是影像加纵向临床表型，不应夸称 omics 融合；价值在治疗前预测而非单纯病例—对照差异。
- **局限/未来**：需更大多中心、药物/依从性控制、嵌套建模、校准和临床决策增量；相关预测不说明治疗机制。

### L04 Mapping brain synergy dysfunction in schizophrenia（2024）

- **研究问题/对象**：全脑信息协同/冗余异常如何解释精神分裂症个体差异及其分子对应；538 名患者与 540 名对照。
- **数据/方法**：区域 BOLD 时序构造 synergy/redundancy 矩阵；层级贝叶斯模型提取三个潜在因子；结合规范性基因表达、NeuroSynth、分子影像资源和空间异质 mean-field model。
- **主要发现**：发现区域特异的 synergy dysfunction；三个潜因子分别对应不同 PANSS 症状模式，并与不同风险基因子集/候选认知和分子机制对应。
- **为什么多模态**：fMRI 描述宏观信息交互，临床量表锚定症状，规范性分子图谱提出跨尺度解释。
- **局限/未来**：规范性表达图谱不是同一被试的分子测量，空间自相关可造成虚假对应；需独立样本、spin/null model 和个体级多组学验证。

### L05 Disorder-specific neurodynamic features in schizophrenia（2024）

- **研究问题**：如何从共享变化中分离精神分裂症特异的宏观动力学特征，并对应症状与分子机制。
- **数据/对象/方法**：多中心影像；将 neurodynamic model 与 contrastive VAE 结合，提取个体/区域参数和时变状态；用 RSA、分类、吸引子分析及 PLS 映射症状。
- **主要发现**：模型得到可拟合的疾病特异特征；疾病特异/共享状态在 attractor space 有差异；两个症状相关模式分别对应阴性/一般症状与阳性症状，并呈不同分子对应。
- **为什么多模态**：动力学模拟连接微观假设与宏观 fMRI，症状和分子图谱提供外部锚定；但“跨尺度”仍是模型约束下解释。
- **局限/未来**：复杂模型可能不可辨识、过拟合；需消融、简单基线、跨中心外部验证和参数稳定性分析。

### L06 Neuroimaging and multiomics reveal cross-scale circuit abnormalities in schizophrenia（2023）

- **研究问题**：题名表明通过神经影像与多组学寻找精神分裂症跨尺度环路异常。
- **证据边界**：当前只核验元数据，未取得摘要；不补写样本、具体组学层、脑环路或效应方向。
- **为什么多模态**：概念上，影像定位宏观环路，multiomics 描述遗传/转录/蛋白等层级；价值在不同层证据是否收敛。
- **局限与精读任务**：核查组学是否来自同一被试、空间图谱还是独立数据库；融合策略、空间自相关零模型、复现队列和是否仅相关映射。
- **未来/可能追问**：真正的跨尺度机制需要纵向或实验操纵，而不只是脑图与基因图的空间相关。

### L07 Hierarchical fluctuation shapes a dynamic flow linked to consciousness（2023）

- **研究问题**：皮层单峰—跨模态层级上的自发波动如何与意识状态、整合和唤醒联系。
- **数据/方法**：人类静息态神经影像，改变意识状态/精神病性状态；quasi-periodic pattern 与宏观梯度；猴 ECoG；转录组与结节乳头核功能连接图谱。
- **主要发现**：层级波动指标对个体意识状态敏感，在迷幻药与 psychosis 下异常升高；传播波与唤醒相关，猴 ECoG 有相似模式；空间分布对应组胺能系统表达和相关核团连接。
- **为什么多模态/电生理作用**：fMRI 给全脑空间流，ECoG 提供更直接时间动力学的跨物种趋同证据，转录组提出组胺能约束。
- **局限/未来**：状态差异可能含运动、药理和唤醒混淆；跨模态相似不等同同一机制，转录图谱对应也非因果。

### L08 miR-134 mechanisms in major depressive disorder using imaging transcriptomics（2023）

- **研究问题**：题名显示用群体与个体化 imaging transcriptomics 研究 miR-134 与抑郁症的神经机制。
- **证据边界**：当前未获得可核验摘要；不补写样本、脑区、方向或中介结论。
- **为什么多模态/组学作用**：miRNA 提供分子调控层，影像提供全脑表型；population-based 与 person-specific 的关键区别应以原文定义为准。
- **局限与精读任务**：确认 miR-134 是否同一被试测量、如何映射到影像、药物和病程控制、空间置换及外部验证。
- **未来/可能追问**：影像转录组关联是生成机制假设的桥梁，需要细胞/纵向/干预证据验证。

### L09 Development of cortical functional hierarchy and molecular organization（2022）

- **研究问题/对象**：儿童皮层功能层级如何发展，是否与产前/产后分子组织相关；学龄前 141 次扫描（2.41-6.90 岁），另在 HCP-D 638 次扫描和 PNC 795 人（约 5.58-21.92 岁、8-21 岁）检验。
- **数据/方法**：rs-fMRI 功能层级/梯度、一般线性模型；结合 Allen Human Brain Atlas 与 BrainSpan 转录组。
- **主要发现**：跨模态区与感觉运动区随发育进一步分离；两个具有不同富集特征的产前/产后基因簇可能对应这一变化，后续年龄数据呈类似轨迹。
- **为什么多模态**：影像给发育中的宏观功能组织，转录组提供可能的时间性分子背景。
- **局限/未来**：扫描次数不等于独立人数；成人供体/群体表达图谱映射儿童需谨慎。需纵向同人数据与更匹配的分子资料。

### L10 Brain age in typical and atypical development（2021）

- **研究问题/对象**：结构和功能影像能否建立考虑性别的脑龄模型，并刻画自闭症发育异质性。
- **数据/方法**：T1 结构 MRI、静息态 fMRI，PLS regression 与 stacking；在四个不同族群/年龄范围的独立数据集验证。
- **主要发现**：多模态、性别特异模型具有跨数据集泛化；群体层面自闭症脑龄差更小，但个体中“提前发育”亚组 ADOS 更高，显示群体均值掩盖异质性。
- **为什么多模态**：结构与功能捕捉不同发育轨迹；stacking 属 late fusion，可比较每个模态及组合的增量。
- **局限/未来**：brain-age gap 易受年龄偏倚、站点和训练范围影响；“提前/延迟”是模型尺度描述，不能直接等同生物成熟机制。

## 3. 七个方向要能讲清

| 方向 | 一句话定义 | 核心价值 | 最大挑战 |
|---|---|---|---|
| MRI + EEG | 联合空间精细但慢的 BOLD/结构与时间精细的电活动 | 定位“哪里”并追踪“何时” | 同步、源定位、血流—电活动耦合和维度不平衡 |
| MRI + genetics | 将影像表型与遗传变异/PRS 关联 | 研究易感性到脑表型的路径 | 小效应、祖源偏倚、多重比较、横断因果不足 |
| imaging genomics | 系统连接遗传变异与个体影像差异 | 个体级基因—脑关联 | 大样本与可复制性 |
| imaging transcriptomics | 将脑空间表型与基因表达图谱对应 | 提出区域分子解释 | 常为不同供体，空间自相关和反向推断 |
| multimodal fusion | 特征级、共同表征或决策级整合 | 检验互补和增量信息 | 缺失模态、批次效应、过拟合、可解释性 |
| multi-omics | 联合基因组、转录组、蛋白/表观等层 | 描述调控链和跨层收敛 | 尺度、组织、时间点不一致及高维小样本 |
| psychiatric/developmental neuroscience | 在病程和发育轨迹中研究脑—行为异质性 | 超越静态病例—对照均值 | 用药/病程/站点混淆，年龄非线性和纵向缺失 |

## 4. 刘冰组必须知道的 20 个概念

| 概念 | 面试最低合格解释 |
|---|---|
| 1. multimodal neuroimaging | 联合互补测量回答同一问题，不等于简单拼接。 |
| 2. structural MRI | 宏观形态/组织信息，不能单独说明实时功能。 |
| 3. diffusion MRI/tractography | 估计白质方向和候选通路；不是直接看到轴突或方向性因果。 |
| 4. resting-state fMRI | 无显式任务的 BOLD 协变，易受头动、警觉和生理噪声影响。 |
| 5. electrophysiology | 更直接且时间精细的群体电活动，空间解释依记录方式而异。 |
| 6. functional gradient | 连续组织轴，避免把脑只切成离散模块；结果依嵌入与预处理。 |
| 7. connectopic mapping | 在一个结构内刻画连接的连续空间变化。 |
| 8. brain dynamics | 状态、波动、驻留和转移；先验证可靠性再赋心理含义。 |
| 9. synergy/redundancy | 多源联合信息中独有的协同/重复部分；依赖估计定义和样本。 |
| 10. attractor | 动力系统趋向的稳定区域；模型吸引子不等于真实神经实体。 |
| 11. PRS | 多遗传变异效应的加权和，预测力和可迁移性受 GWAS/祖源限制。 |
| 12. imaging genomics | 个体遗传与影像表型的关联研究。 |
| 13. imaging transcriptomics | 影像空间图与表达图谱对应，常是群体/规范性而非同人。 |
| 14. multi-omics | 联合多个分子层，需处理尺度、批次和高维问题。 |
| 15. early/intermediate/late fusion | 特征拼接、共同潜空间、决策合并，各有交互捕捉与稳健性取舍。 |
| 16. normative model | 建立年龄等条件下的正常分布，再看个体偏离。 |
| 17. brain age gap | 预测脑龄减实际年龄；须校正年龄偏倚，不能直译为成熟快慢机制。 |
| 18. heterogeneity | 同一诊断可有不同症状和脑模式，群体均值可能掩盖亚型。 |
| 19. external validation | 在独立中心/队列锁定流程测试，区别于同数据交叉验证。 |
| 20. spatial autocorrelation null | 脑图邻近位置天然相似，需保空间结构的零模型检验跨图对应。 |

## 6. 你的项目如何对接而不夸大

- **已有桥梁**：EEG/ERP、n-back、动态网络、HMM/CHMM、焦虑评估和情绪网络，使你能处理时间动力学并理解外部行为锚定。
- **需要补齐**：MRI 测量逻辑、发育与精神病理构念、多中心泛化、遗传/转录组证据层级。
- **推荐表达**：“我希望把已有的动态建模能力用于可检验的心理问题，例如状态占用是否随工作记忆负荷或症状维度按预注册假设改变；进入多模态场景后，我会先比较 EEG、MRI 单模态基线，再检验融合的增量和跨中心泛化，而不会把共同表征直接称为机制。”

精读顺序建议：L10 建立多模态与发育，L09 理解梯度和转录组，L07 学习影像—电生理—转录的趋同证据，L03 学习临床预测，L04/L05/L06 学习精神分裂症的异质性与跨尺度解释。L01、L06、L08 在拿到原文后再补精确样本和结果。
