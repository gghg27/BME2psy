# 04 中文文献评论：30 分钟批判框架

> 目标不是“挑错越多越好”，而是判断证据是否支持主张，并提出能区分替代解释的改进。材料均为考试化改写，不复制论文正文。

## 1. 20 维检查框架

| 模块 | 检查项 | 一句话追问 |
|---|---|---|
| 问题与理论 | 问题、理论、假设 | 问题是否具体？理论如何推出方向性预测？什么结果可推翻？ |
| 样本 | 总体、抽样、样本量、纳排 | 样本代表谁？是否为主效应/交互做功效设计？剔除是否事先定？ |
| 构念与测量 | IV 操作化、DV 效度、操纵检验 | 操作只改变目标构念吗？主终点可靠且有效吗？ |
| 设计 | 因果识别、对照、随机、盲法、顺序 | 设计能回答问题吗？最大混淆和需求特征是什么？ |
| 统计 | 方法匹配、多重比较、效应量/CI、假设 | 分析单位对吗？核心检验是交互吗？是否选择性报告？ |
| 解释 | 结果-结论、相关/因果、替代解释 | 数据直接支持哪一层？作者跨过了哪些证据台阶？ |
| 质量 | 内/外部效度、可重复、透明度 | 能否复现？是否预注册、开放材料/代码、外部验证？ |
| 推进 | 局限、改进、下一步 | 改进是否真正区分解释，而非只说“扩大样本”？ |

## 2. 30 分钟作答模板

### 0-5 分钟：复原研究

用六句话写：问题、理论、样本、IV/DV、核心结果、作者结论。圈出所有因果词和“首次/证明/生物标志物”等强主张。

### 5-20 分钟：抓三条主线

1. **最强优点**：设计中最能支持结论的一点。
2. **致命问题**：若成立，会让核心结论无法成立的问题。
3. **两个重要但次级问题**：测量、统计或推广性。

每条按 `问题 → 为什么影响推断 → 如何改进 → 改进后能回答什么` 写，不做清单式吐槽。

### 20-27 分钟：提出 follow-up

给一个能区分至少两个解释的实验：明确假设、IV、DV、设计、控制、核心交互和预期模式。

### 27-30 分钟：压缩结论

“该研究提供了 X 层证据，优点是 Y；但因 Z，尚不能支持作者的强结论。最关键的下一步是 W。即使 W 得到支持，结论仍限于该样本、操作和测量。”

## 3. 十道模拟材料

### 题 1：负性情绪与疼痛

【材料】研究者让 30 名大学生依次观看负性图片和中性图片，并在每张图后给予热刺激。负性条件的疼痛评分更高，作者据此称“负性情绪导致疼痛系统敏感化”。所有被试先做负性组块，图片的唤醒度未匹配，只报告 `p=.04`。

【问题】指出核心优点、三个主要问题；提出能区分效价与唤醒的改进；作者的因果结论可保留到哪一层？

【我的答题区】研究复原：____。致命问题：____。改进：____。边界：____。

【参考分析】组内设计提高效率，但固定顺序把条件与疲劳/适应混淆；效价与唤醒共变；样本小且只报 p 值。应正交操纵效价×唤醒、随机/反平衡顺序，预定主终点并报告差值 CI。现有证据只支持该程序下负性组块与更高自评相关，不能归因于情绪效价，更不能推出长期“敏感化”。

### 题 2：n-back 与儿童注意

【材料】研究招募一所小学的两个班，一个班接受 4 周 n-back 训练，另一班正常上课。训练班训练后 Stroop RT 更快，研究者称工作记忆训练提高了儿童一般执行功能。两班由校方指定，前测训练班 RT 更慢。

【问题】识别选择偏差、回归均值和迁移测量问题；设计更强的对照。

【我的答题区】____

【参考分析】班级分配不是随机且基线不等；慢组更可能自然回归。正常上课不能控制接触、期待和奖励。应以班级为随机单位或匹配后集群随机，采用主动对照，预注册远迁移主终点，并用 group×time 模型及集群随机效应。Stroop 改善也可能来自速度-准确权衡，应同时报告错误率。

### 题 3：抑郁注意偏向

【材料】研究比较 20 名抑郁患者与 20 名健康人 dot-probe bias score，患者均值更高但差异不显著。作者写“抑郁患者不存在负性注意偏向”。该差值分数的重测信度为 .20。

【问题】为什么非显著不能证明不存在？低信度怎样影响结论？如何改进？

【我的答题区】____

【参考分析】非显著可能来自低功效和宽 CI；应给最小重要效应并做等价检验。低信度会衰减关联、放大不稳定个体差异。可增加 trial、用 trial-level hierarchical model、采用眼动/时间进程指标并验证重测可靠性。结论应是“当前数据不足以区分零效应与有意义效应”。

### 题 4：EEG 疼痛标志物

【材料】研究从 64 导 EEG 提取 5000 个特征，在 50 人中筛出与疼痛评分相关的 30 个特征，再用同一批数据十折交叉验证，准确预测高/低疼痛并称发现临床标志物。高低标签按全样本中位数划分。

【问题】指出泄漏、分箱与临床效用问题；给出验证路线。

【我的答题区】____

【参考分析】若特征筛选在交叉验证外完成，测试折信息已泄漏；中位数切分损失连续信息且标签依赖当前样本。应把全部预处理/选择/调参放入 nested CV，保留连续结局，锁定模型后做跨日、跨刺激、跨中心外部验证，并评估校准、相对临床变量的增量效度和决策效用。

### 题 5：功能连接与焦虑病因

【材料】一次横断静息态研究发现杏仁核-mPFC 连接与焦虑量表 `r=-.35`，控制年龄和性别后仍显著。作者称连接下降是焦虑的神经病因。

【问题】列出三种因果结构；控制协变量解决了什么、没解决什么？

【我的答题区】____

【参考分析】可能是连接→焦虑、焦虑/压力→连接，或睡眠、药物、头动等共同原因。控制年龄性别只在模型正确且无测量误差时处理两项已测混淆，不能排除反向因果和未测混淆。需要纵向跨滞后、自然实验或神经调控加行为结局，并先控制头动质量。

### 题 6：安慰剂镇痛

【材料】患者在治疗前后接受相同热刺激，治疗后疼痛下降。研究人员和患者都知道治疗，并告诉患者该方法有效。作者把前后差称为“特异性神经调控效应”。

【问题】需要哪些对照？如何区分自然变化、期待和特异作用？

【我的答题区】____

【参考分析】前后差混合自然病程、回归均值、重复适应、期待和报告需求。至少加入 sham 与无治疗/等待对照，随机分配，尽量盲被试与评分者，测期待和盲法猜测。核心比较是 active-sham；等待组帮助估计自然变化。即使 active 优于 sham，也需检查非特异感觉差异。

### 题 7：双因素结果误读

【材料】患者组中高负荷相对低负荷显著降低正确率（p<.01），健康组差异不显著（p=.12），作者据此称负荷只影响患者。组别×负荷交互 `p=.28`。

【问题】作者错在哪里？正确报告什么？

【我的答题区】____

【参考分析】“显著/不显著”之差不等于效应差显著；直接交互不显著。应报告每组负荷效应及 CI、两效应之差的 CI，并避免“只影响”。若研究问题是等价，应预定等价界值和功效，而不是依赖交互不显著。

### 题 8：fMRI 情绪调节

【材料】重评条件相对观看条件降低杏仁核 BOLD，提高 dlPFC BOLD；作者称 dlPFC 抑制杏仁核从而降低情绪。两个条件的反应时和眼动不同，未测主观情绪。

【问题】区分参与、方向和心理效果三层证据；提出补充测量。

【我的答题区】____

【参考分析】对比只说明区域活动差异，与调节参与一致；同时出现相反 BOLD 不证明 dlPFC→杏仁核的抑制定向。又因缺少体验/生理结局，不能确认情绪真的降低。应加入情绪评分、自主生理、眼动和难度匹配；用模型比较或干预增强方向证据，但仍需明确模型假设。

### 题 9：多中心精神疾病分类

【材料】模型随机把来自 5 家医院的所有被试分成训练和测试集，AUC=.88。疾病组主要来自医院 A/B，对照主要来自 C/D/E。作者称模型识别精神分裂症神经特征。

【问题】最大混淆是什么？如何划分数据与验证？

【我的答题区】____

【参考分析】医院/扫描仪与诊断高度共线，随机个体划分让模型利用站点特征。应在设计阶段让各站点同时包含患者/对照，训练中建模站点，并做 leave-one-site-out 与完全独立站点验证。检查模型能否单独预测站点、在站点内是否仍有效，并报告校准与亚组稳定性。

### 题 10：中介机制

【材料】横断问卷显示童年压力与成人疼痛相关，当前抑郁得分统计中介了 40% 的关联。作者称童年压力“通过导致抑郁”增加疼痛。

【问题】统计中介为何不等于机制？需要哪些假设和研究？

【我的答题区】____

【参考分析】三变量同测无法确认时间顺序；压力-抑郁、抑郁-疼痛和压力-疼痛路径都可能有未测混淆，疼痛也可能影响抑郁回忆。间接效应只是给定模型下的分解。需要纵向多时点、可靠测量、明确混淆集，最好利用干预抑郁或自然实验，并做替代方向与敏感性分析。

## 面试高频问题

1. 文献评论是否必须找出“致命缺陷”？找不到时怎么办？
2. 为什么“扩大样本”通常不是最有信息量的改进？
3. 如何评价作者结论的强度，而不只是重复局限？
4. 一个 follow-up experiment 怎样真正区分替代解释？
