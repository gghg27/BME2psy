# 06 从工程语言到心理学/认知神经科学语言

> 目标：解释证据，不讲算法实现。四层顺序固定为：**心理构念 → 操作化/行为 → 神经指标 → 解释边界**。

## 1. 先改掉六种说法

| 工程式说法 | 面试可用说法 |
|---|---|
| “两通道 PLV 升高，所以信息传递增强。” | “该条件下两信号相位关系更稳定，与功能协同一致；但共同源、体积传导和参考会造成虚假连接，PLV 也不给方向和因果。” |
| “P300 是注意成分。” | “P3 振幅受任务相关性、概率、证据更新和资源分配影响；当前效应与注意分配一致，但需结合任务对照、潜伏期和行为。” |
| “模型准确率 90%，找到了生物标志物。” | “模型在当前数据划分中有辨别力；成为 biomarker 还需嵌套验证、独立外部验证、校准、增量效度和临床效用。” |
| “某脑区被激活，因此它负责该功能。” | “该区域在任务对比中 BOLD 更高，与该过程参与相容；但任务差异、反向推断和网络协同限制功能归属。” |
| “HMM 状态代表三种情绪。” | “HMM 得到三类复现的信号动力学状态；只有状态占用/转换与独立情绪操纵和行为稳定关联，才可讨论其心理意义。” |
| “连接预测焦虑，因此是病因。” | “连接对症状有样本外预测信息；横断观察不能区分病因、后果或共同混淆。” |

## 2. 模态能告诉你什么

| 方法 | 主要证据 | 强项 | 关键局限 | 合理句式 |
|---|---|---|---|---|
| EEG | 头皮电位的时间变化 | 毫秒时间分辨率 | 源定位不适定、参考/伪迹 | “效应出现在约 X ms，与某加工阶段的时间进程一致” |
| ERP | 与事件锁定的平均电位 | 识别阶段性差异 | 平均会抹平非相位锁定活动；成分非单功能 | “条件改变了该时间窗/拓扑下的事件相关反应” |
| time-frequency | 功率/相位随时频变化 | 诱发与非相位锁定动力学 | 频带边界、1/f、基线选择 | “某频段活动在该任务和时间窗变化” |
| functional connectivity | 统计依赖 | 描述网络协同 | 共因、泄漏，不给方向 | “连接差异与协同变化一致” |
| effective connectivity | 模型下的定向影响 | 比 FC 更接近机制比较 | 强依赖模型与假设 | “在候选模型集合中更支持 A→B” |
| fMRI/BOLD | 血氧动力学间接反映神经活动 | 空间覆盖与定位 | 延迟、血管因素、运动 | “任务对比下区域/模式 BOLD 改变” |
| MVPA | 分布式模式是否区分/预测 | 利用多变量信息 | 可解码不等于脑在这样读出 | “模式含有关于条件的信息” |
| RSA | 神经表征距离与模型距离对应 | 比较表征结构/跨模态 | 模型共线、距离选择 | “表征几何更接近模型 X” |
| neuromodulation | 操纵神经系统后看行为变化 | 提供更强因果证据 | 空间扩散、非特异感觉、盲法 | “在控制感觉/期待后，操纵改变了行为” |

## 3. ERP 高频成分

| 成分 | 大致时间 | 常见任务/相关过程 | 解释提醒 |
|---|---:|---|---|
| P1 | 70-130 ms | 视觉空间注意、低级视觉 | 对比度和眼动也影响；非“注意专属” |
| N1 | 80-180 ms | 感觉辨别、选择性注意；激光 N1 | 拓扑和参考重要；激光 N1 与早期伤害感受加工相关 |
| P2 | 150-250 ms | 刺激评价、显著性 | 与 N2/P2 复合和物理强度混淆 |
| N2 | 200-350 ms | 冲突、抑制、偏差检测 | 稀有性/难度也变；需匹配条件 |
| P3/P300 | 300-600 ms | 任务相关性、证据更新、资源分配 | 概率、信心、RT 都影响；P3a/P3b 有别 |
| N400 | 300-500 ms | 语义预期违背/整合 | 不等于“语义错误探测器”；上下文可预测性关键 |
| LPP | 400 ms 后 | 持续情绪/动机显著性 | 唤醒、注意和图片特征共变 |
| ERN | 错误后约 0-100 ms | 错误/冲突监测 | 错误数量和反应锁定信噪比要控制 |
| laser N2-P2 | 约 180-400 ms | 显著伤害感受事件 | 强烈受注意和显著性影响，不能当疼痛专属读数 |

## 4. 频段不是功能标签

| 频段 | 常见范围 | 可讨论的现象 | 禁止的机械等同 |
|---|---:|---|---|
| delta | 1-4 Hz | 慢波、睡眠、长时整合 | “delta=无意识” |
| theta | 4-8 Hz | 记忆控制、冲突、海马-额协同 | “theta=工作记忆” |
| alpha | 8-13 Hz | 感觉抑制、注意定向、警觉 | “alpha下降=激活增强”在所有情境成立 |
| beta | 13-30 Hz | 感觉运动维持/更新、top-down | “beta=运动” |
| gamma | 30 Hz 以上 | 局部群体活动、感觉/疼痛相关同步 | 忽略肌电、窄带/宽带和基线；“gamma=疼痛” |

报告时写清中心频率、时间窗、位置、基线、诱发/自发、功率/相位和多重比较。先说“与……一致”，再说替代解释。

## 5. 脑区与网络速查

| 区域/网络 | 大致位置 | 常见主题 | 典型误读 |
|---|---|---|---|
| PFC/dlPFC | 额叶外侧 | 工作记忆、规则、控制、调节 | “PFC 活跃=更高级/更努力” |
| vmPFC/OFC | 腹内侧/眶额 | 价值、情境、安全/期待 | 将相关活动等同单一价值计算 |
| ACC | 内侧额叶 | 冲突、成本、疼痛/显著性 | “疼痛中心”或“冲突中心” |
| PCC | 后内侧 | 自传/内部加工、DMN | 静息连接变化即自我加工异常 |
| insula | 外侧裂深部 | 内感受、显著性、疼痛 | “疼痛岛” |
| amygdala | 内侧颞叶 | 生物意义、学习、威胁 | “恐惧中心”；也响应正性/新异 |
| hippocampus | 内侧颞叶 | 情景/关系记忆、情境 | 所有记忆都归海马 |
| thalamus | 间脑 | 感觉门控、皮层环路 | 仅是被动中继 |
| S1/S2 | 顶叶躯体感觉区 | 体感位置/强度、整合 | 活动=主观疼痛充分条件 |
| M1/SMA | 运动/内侧额叶 | 动作执行、准备、序列 | 任务差异含按键却解释为认知 |
| striatum | 基底节 | 奖励、动作选择、学习 | 只等同愉悦 |
| DMN | PCC-mPFC-顶叶等 | 内部导向、情境模型 | “任务负网络”或走神专属 |
| salience network | anterior insula/dACC 等 | 行为相关事件检测与切换 | 所有显著刺激同一机制 |
| frontoparietal | 额顶 | 灵活控制、多任务 | 单一固定网络模块 |
| DAN/VAN | 背侧/腹侧注意网络 | 目标定向/重定向 | 自上而下/自下而上一一对应 |

## 6. 动态网络与 HMM 的心理解释路径

1. **状态可靠性**：跨初始化、被试子样本、参数和预处理是否复现？
2. **独立锚定**：状态是否随外部任务事件、负荷、评分或临床变量按预设改变？
3. **排除伪解释**：头动、眼动、肌电、全局信号、扫描时长是否同步改变？
4. **个体层泛化**：占用率/转移率在留出数据或新样本能否预测行为？
5. **解释层级**：称“动力学状态”，除非有足够证据，不直接命名“焦虑状态/情绪网络”。

### 项目表达模板

“我用 HMM/CHMM 描述多通道信号在时间上的重复协方差模式，问题不是聚类本身，而是这些状态是否随认知负荷/情绪条件系统变化，并与行为存在可复现关联。模型提供描述和预测证据；若没有操纵或纵向证据，我不会把状态转移解释为心理过程的因果机制。”

## 7. 多模态融合的三层

- **early fusion**：特征级拼接；保留交互但受尺度、缺失和维度灾难影响。
- **intermediate fusion**：共同潜空间/联合表征；适合跨模态共享与特异信息，但可解释性依赖模型。
- **late fusion**：各模态独立预测后合并；稳健、易处理缺失，但可能错过细粒度交互。

MRI 给结构/空间组织，fMRI 给血氧动力学功能，EEG 给时间动力学，遗传/转录组给跨尺度分子背景。融合的价值是互补证据，不是“模态越多越好”。必须比较单模态基线、增量效度和缺失模态性能。
