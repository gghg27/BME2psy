    03 心理学统计：从设计到方法¶

    你已有概率统计基础。本章只解决三件事：选方法、读结果、抓错误。设计术语见 02_experimental_design.md。

    1. 统计方法选择树¶

    1. 主问题是什么？比较、关联、预测、分类，还是潜变量/信度？
    2. DV 类型？连续、二分类、计数、时间到事件；这决定模型族。
    3. 观测独立吗？同一被试/刺激重复出现时，优先重复测量方法或 mixed-effects model。
    4. 几个 IV，各几水平？一个两水平可 t；多水平/多因素用 ANOVA 或回归编码。
    5. 核心是否为交互？直接检验交互项，不能用“一组显著、另一组不显著”。
    6. 协变量是否操纵前确定？ANCOVA/回归可以提高精度，但不能机械“控制”中介或受处理影响变量。
    7. 假设严重不满足吗？检查残差、离群、方差结构；考虑稳健、变换、广义或非参数方法。
    场景 首选 核心零假设 看什么 常见错误
    两独立组连续 DV independent t-test 两总体均值差为 0 mean difference、CI、d 忽略方差不齐；默认可用 Welch
    同一人前后 paired t-test 配对差均值为 0 difference CI、paired d 当独立样本处理
    一因素 ≥3 独立组 one-way ANOVA 所有组均值相等 omnibus F、η²、计划比较 F 显著后随意两两 t
    两因素独立/析因 two-way ANOVA 各主效应/交互为 0 交互优先、simple effects 只报主效应
    同一人 ≥3 条件 RM-ANOVA 条件均值相等 F、partial η²、球形校正 忽略 sphericity/缺失
    组别×时间 mixed ANOVA 组别、时间、交互为 0 group×time interaction 用组内显著性判断组间差异
    连续 DV + 预先协变量 ANCOVA 调整后组差为 0 adjusted difference、斜率同质 控制处理后的变量
    两连续变量线性关联 Pearson ρ=0 r、CI、散点与非线性 离群点驱动；误作因果
    等级/单调非线性 Spearman rank ρ=0 ρs、CI 以为无需任何假设
    控制第三变量相关 partial correlation 条件线性相关为 0 partial r “控制”不能消除未测混淆
    连续结局预测 linear regression β=0 β、CI、残差、R²/增量 数据泄漏、共线、过拟合
    多预测变量 multiple regression 条件 β=0 adjusted R²、每项 β/CI 逐步回归后当验证性分析
    二分类结局 logistic regression log-odds β=0 OR、CI、校准/辨别 把 OR 当风险比；小样本分离
    重复 trial/被试/刺激 linear mixed-effects 固定效应为 0 fixed effect CI；随机结构 只给被试随机截距，忽略刺激
    明显等级/小样本稳健比较 Mann-Whitney/Wilcoxon 分布位置/秩关系 秩效应与 CI 误称“中位数检验”

    2. 结果解释必会¶

    • p value：在模型与零假设成立时，观察到当前或更极端数据的概率；不是零假设为真的概率。
    • 95% CI：在重复抽样意义下，构造程序约 95% 覆盖真值；关注范围是否包含重要效应，而不只看是否跨 0。
    • effect size：效应大小。Cohen's d 用标准差单位；η²/partial η² 表示特定方差比例，但二者不可混写。
    • power：给定真实效应、样本量和 α 时拒绝错误零假设的概率；事后“observed power”通常无信息增量。
    • Type I/II error：假阳性/假阴性。提高样本量可降低 II 类错误；单纯降低 α 会在样本固定时提高 II 类风险。
    • multiple comparisons：Bonferroni 控制 family-wise error，保守；FDR 控制发现中的期望假比例，适合多特征探索。必须先定义 family。

    3. 假设与修复¶

    假设 检查对象 违反后优先做什么
    normality 模型残差/配对差，不是每组原始值机械检验 看 Q-Q 与影响点；大样本下重视稳健性
    homogeneity 条件残差方差 Welch t/ANOVA、稳健 SE 或显式方差模型
    sphericity 多水平组内差值方差结构 Greenhouse-Geisser 校正或 LMM
    independence 设计产生的依赖结构 cluster/mixed model；不能靠正态检验修复
    linearity 条件均值与预测变量关系 图形、非线性项/spline；避免盲目分箱

    4. 心理学常见扩展¶

    • mediation：X 通过 M 关联 Y；估计间接效应 a×b 及 bootstrap CI。若时间顺序和混淆不可控，只能称统计中介，不称机制已证实。
    • moderation：X 的效应随 Z 改变；在回归中检验 X×Z，连续 Z 尽量不按中位数切组。
    • Cronbach's alpha：项目在 tau-equivalent 等假设下的内部一致性；高 alpha 不证明单维或效度，项目冗余也会抬高。
    • test-retest reliability：跨时间稳定；要说明时间间隔和构念本身是否应稳定。
    • ICC：评定者/测量的一致性或绝对一致性；必须报告具体 ICC 类型、单次/平均测量。
    • EFA/CFA：EFA 探索载荷结构，CFA 检验预设结构；最好不同样本或交叉验证。拟合好不等于理论为真。

    5. 论文结果怎么读¶

    例：emotion × attention: F(1,78)=6.10, p=.016, partial η²=.073。

    正确表述：“情绪效应随注意条件变化，交互效应约解释该误差结构下 7.3% 的可归属方差；还需查看预先设定的简单效应和均值 CI。”不要写成“负性情绪显著导致疼痛”，除非设计与效应方向共同支持。

    例：OR=1.80, 95% CI [1.20, 2.70]。

    正确表述：“预测变量每增加一个单位，结局 odds 乘以 1.80；这不是概率增加 80%，也未自动说明因果。”

    6. 题库（仅题目）¶

    答案见 03_statistics_for_psychology_answers.md。

    A. 给设计选方法（20 题）¶

    1. 两独立组比较疼痛评分。 2. 同一人 placebo 前后评分。 3. 三种刺激强度、不同人各参加一种。 4. 同一人完成四种情绪条件。 5. 患者/对照在基线与治疗后测量。 6. 性别×情绪条件均为组间。 7. 组别×n-back 负荷，负荷组内。 8. 连续焦虑分与正确率关联。 9. 等级疼痛与偏态睡眠质量关联。 10. 控制年龄后看脑连接与症状相关。 11. 连续症状由年龄、连接、性别预测。 12. 是否复发由多项基线指标预测。 13. 每人 200 个 trial 的 RT。 14. 被试与图片都重复出现。 15. 三个时点且部分缺失。 16. 两组序数满意度且小样本。 17. 三个评定者评价同一访谈。 18. 10 项量表内部一致性。 19. 检验量表预设三因子结构。 20. 检验焦虑是否改变情绪对疼痛的效应。

    B. 解释结果（10 题）¶

    1. d=0.50, CI [0.08,0.92], p=.02。 2. p=.08, CI [-0.05,0.70]。 3. 交互显著但两主效应不显著。 4. 主效应显著但交互不显著。 5. r=.40 的含义与限制。 6. OR=2.0。 7. FDR 后 q=.04。 8. alpha=.92。 9. ICC=.75。 10. 模型 AUC=.85 但外部样本 AUC=.61。

    C. 找错误（10 题）¶

    1. 一组 p<.05、另一组 p>.05，所以组间效应不同。 2. 300 个 trial 当 N=300。 3. 按结果删除离群点。 4. 做 40 个检验只报告两个显著。 5. 相关显著所以 X 导致 Y。 6. alpha 高所以量表有效。 7. ANCOVA 控制治疗后的中介。 8. 训练/测试混合后报告准确率。 9. 非显著就证明两组等价。 10. 球形性违反仍报告未校正 RM-ANOVA。
