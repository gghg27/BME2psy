    13 程序设计专项练习（仅题目）¶

    先独立作答，再查看 参考答案。P01-P16 每题建议 20-35 分钟；P17-P18 各限时 180 分钟。

    作答要求¶

    每题提交前写出：算法思路、核心不变量、时间/空间复杂度、至少 3 个测试用例。默认使用 Python 3 标准库。

    A. 基础模式¶

    P01 词频最高的编号¶

    给定整数列表，返回出现次数最多的整数。次数相同时返回较小值。空列表返回 None。

    示例：[4, 2, 4, 2, 2] -> 2。目标复杂度：O(n)。

    P02 去重并保持顺序¶

    删除列表中的重复元素，保留每个元素第一次出现的顺序。

    示例：[3, 1, 3, 2, 1] -> [3, 1, 2]。目标复杂度：均摊 O(n)。

    P03 三数之和¶

    给定整数数组，返回所有和为 0 的不重复三元组。三元组内部升序，结果按字典序排列。

    示例：[-1, 0, 1, 2, -1, -4] -> [[-1, -1, 2], [-1, 0, 1]]。目标复杂度：O(n^2)。

    P04 旋转数组中的最小值¶

    一个严格递增数组被旋转一次，例如 [4, 5, 1, 2, 3]。返回最小值；数组非空且无重复元素。

    目标复杂度：O(log n)。

    P05 每日温度¶

    对每一天，返回还要等待多少天才会出现更高温度；之后没有更高温度则为 0。

    示例：[73, 74, 75, 71, 69, 72, 76, 73] -> [1, 1, 4, 2, 1, 1, 0, 0]。目标复杂度：O(n)。

    P06 长度最小的连续子数组¶

    给定正整数数组和 target，返回和大于等于 target 的最短连续子数组长度；不存在则返回 0。

    示例：target=7, nums=[2, 3, 1, 2, 4, 3] -> 2。目标复杂度：O(n)。

    P07 最近 k 次测量的移动平均¶

    返回每个完整窗口的平均值。若 k <= 0 或 k > len(values)，返回空列表。

    示例：values=[1, 2, 3, 6], k=3 -> [2.0, 11/3]。目标复杂度：O(n)。

    B. 图、搜索与动态规划¶

    P08 岛屿数量¶

    字符矩阵中 "1" 是陆地，"0" 是水。上下左右相邻的陆地属于同一岛屿，返回岛屿数量。

    示例：[["1","1","0"],["0","1","0"],["1","0","1"]] -> 3。

    P09 二分图判断¶

    给定无向图邻接表，判断能否把节点分成两组，使每条边的两个端点属于不同组。图可能不连通。

    目标复杂度：O(V + E)。

    P10 课程安排¶

    有 n 门课，先修关系 (course, prerequisite)。判断是否能完成全部课程。

    示例：n=2, prerequisites=[(1, 0)] -> True；[(1, 0), (0, 1)] -> False。

    P11 带权网格最小代价¶

    每个网格元素是进入该格子的非负代价。从左上角出发，只能上下左右移动，求到右下角的最小总代价，包含起点代价。

    示例：[[1,3,1],[1,5,1],[4,2,1]] -> 7。

    P12 爬楼梯¶

    每次走 1 或 2 级，返回走到第 n 级的方法数。规定 n=0 时有 1 种方法。

    目标复杂度：O(n) 时间、O(1) 空间。

    P13 最少硬币数¶

    给定正整数面额和金额 amount，返回凑出该金额所需的最少硬币数；不能凑出返回 -1。每种硬币可重复使用。

    示例：coins=[1,2,5], amount=11 -> 3。

    P14 最长递增子序列¶

    返回严格递增子序列的最大长度。先实现 O(n^2) 解法，再尝试 O(n log n)。

    示例：[10,9,2,5,3,7,101,18] -> 4。

    C. 国重科研数据场景¶

    P15 状态占用率¶

    给定状态序列和状态数 k，返回每个状态的占用比例。空序列返回 k 个 0.0；状态越界时抛出 ValueError。

    示例：states=[0,1,1,2], k=3 -> [0.25, 0.5, 0.25]。

    P16 被试级数据拆分¶

    记录格式为 (subject_id, trial_id)。给定测试被试集合，按被试返回训练记录和测试记录，并验证两组被试没有交集。

    示例：记录 [('s1',1),('s1',2),('s2',1)]，测试被试 {'s2'}，测试集只能含 s2。目标复杂度：O(n)。

    D. 三小时模拟¶

    P17 模拟一¶

    1. 45 分钟：完成 P03 三数之和，并解释如何去重。
    2. 45 分钟：完成 P10 课程安排，并输出一种可行顺序；有环返回空列表。
    3. 45 分钟：完成 P15，并扩展为同时返回状态转移概率矩阵。没有出边的行保持全零。
    4. 45 分钟：选择一段自己的代码，写出 5 个边界测试并说明复杂度。

    P18 模拟二¶

    1. 40 分钟：实现合并区间和二分查找。
    2. 50 分钟：完成 P08 岛屿数量，分别写递归和迭代版本的取舍。
    3. 50 分钟：完成 P13 最少硬币数，并说明为什么贪心不总是正确。
    4. 40 分钟：设计函数统计每位被试的 trial 数，筛除少于阈值的被试；禁止泄漏测试集信息。

    自评分¶

    每个小题 10 分：正确性 4 分、复杂度 2 分、边界处理 2 分、解释 2 分。低于 7 分的题必须隔一天闭卷重做。
